# BookShelf 
BookShelf is a mobile React Native application developed as part of a Mobile Development exam project at EK.

The app allows users to:

- Create an account and log in
- Search for books through BigBookAPI
- Add books manually
- Save books to reading lists
- Track reading status
- Upload profile and book images
- Edit and delete books
- Rate finished books and add notes

## Technologies Used
- React Native
- Expo
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- BigBookAPI

## Install + Run the Project

### Clone
```bash
git clone <repository-url>
```

### Install dependencies 
```bash
npm install
```

### Run the project
```bash
npx expo start
```

### Note
Firebase and API configuration are already included in the project, so no additional setup is required.
